## 20. Complete current keyword set

The current construction language consists of:

### Global

```text
NETWORKS
MODES
CONTAINERS
```

### Build

```text
FROM
COPY
RUN
```

### Runtime

```text
BIND
NETWORKS
EXPOSE
PORT
PRIORITY
CMD
```

### Filesystem location prefixes

```text
host:
this:
```

plus named filesystem references where applicable.
