these are general guidelines that the project must follow:

the project uses clean architecture

the project respects clean code and SOLID principles and prefers modularity and simplicity 

naming should be clear, no shortcuts, no abbreviations unless they are standards

no sh scripts, if any script is needed it should be a python or go or nodejs script, and should only serve the development process, no scripts are shipped to production by any means

every step should be well commented

every decision should be explained in the ADR, if a decision or a behaviour is altered it should be present in the ADR
